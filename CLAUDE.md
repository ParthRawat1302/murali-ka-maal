# AlgoWeb

Class DSA question tracker (Next.js 16 + Supabase). Setup, accounts and scripts: [README.md](README.md).

## Adding questions from chat

When the user gives you a question to add (LeetCode link, class-notes photo, test question, DomJudge
text), follow **[prompts/process-question.txt](prompts/process-question.txt)** step by step: first check
AlgoWeb for duplicates, then look for the same problem on LeetCode, and only write the question yourself
(with examples, constraints and SVG diagrams) when there's no exact LeetCode match.
